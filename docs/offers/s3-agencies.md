# S3 — Агенції-партнери (субпідряд / white-label)

## Кому
Компанії, які вже продають корпоративним клієнтам фізичні речі, але не мають власного 3D:
бізнес-подарунки й промопродукція, івент-агенції, брендингові студії, виробники нагород.

**Хто вирішує:** власник, продюсер, акаунт-директор.

## Чому це важливо для вас
Один партнер = постійний потік замовлень без вашого аутрічу. Агенція вже має клієнтів і бюджети;
ви — виробництво. Найкраще співвідношення «година продажів → гривня».

## Біль агенції
- Клієнти хочуть «щось незвичне», а каталог — чашки, ручки, павербанки.
- Кастомні фігурки / 3D-нагороди замовити ніде: або дорого і довго, або без фарбування.
- Ризик підрядника: зірвані терміни, нестабільна якість.

## Пропозиція
**Ваша нова категорія в каталозі — кастомні 3D-фігурки, маскоти й нагороди. Без вашого 3D.**
- Працюємо під вашим брендом (white-label): клієнт бачить вас, ми — виробництво.
- Повний цикл: модель з брифу → візуалізація для погодження → друк → ручне фарбування → пакування.
- Тиражі 1–100+ шт.; фарбування масштабуємо через перевірених художників з контролем якості.
- Партнерська ціна: **−15% від нашої ціни для кінцевого клієнта** [?] — агенція ставить свою націнку.
- Швидкий прорахунок: бриф → ціна й термін за 24 год.

**Стартовий крок:** набір зразків для шоуруму / менеджерів (Постать + демо-маскот + демо-нагорода).

## Заперечення → відповідь
- *«У нас є підрядник на 3D»* → Чудово для технічних речей. Ми сильні там, де треба художньо —
  модель з нуля + ручне фарбування. Візьміть нас як другого підрядника на складні проєкти.
- *«Клієнти не просять»* → Бо не знають, що можна. Дайте менеджерам зразок — і це стане
  аргументом, якого немає в конкурентів.
- *«Обійдете нас і підете до клієнта напряму»* → Не працюємо з клієнтами партнерів напряму —
  пропишемо в договорі.
