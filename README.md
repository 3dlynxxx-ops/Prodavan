# AI Creative Digest 🗞

Щоденний дайджест свіжих статей про **ШІ в креативних індустріях** (насамперед архвіз, а також відео, анімація, 3D і вебдизайн), який сам публікується в Telegram-канал маркетинг-відділу.

## Як це працює

```
RSS-стрічки + Google News  →  фільтр (свіжість, ключові слова, дублі)  →  повний текст статті
        →  Claude: оцінка 0–10, заголовок і підсумок українською, ідея для поста  →  Telegram
```

1. Раз на день GitHub Actions запускає скрипт.
2. Скрипт збирає записи з RSS-джерел (`config.yaml` → `sources`) і пошукових запитів Google News.
3. Відкидає старі (понад 48 год), уже надіслані, дублі та нерелевантні (немає згадок ШІ чи креативу).
4. Claude Haiku оцінює кандидатів, пише короткий підсумок українською і пропонує кут подачі для Instagram.
5. Найкращі статті (до 8, з оцінкою від 6) публікуються в канал, згруповані за категоріями.
6. Список уже оброблених статей зберігається в `data/seen.json`, тому повторів не буде.

**Вартість:** GitHub Actions безкоштовний (запуск займає ~1–2 хв із 2000 безкоштовних хвилин на місяць). Claude Haiku коштує приблизно $0.01–0.05 на місяць за такого обсягу. Без ключа Anthropic бот теж працює, але тоді публікує оригінальні англійські заголовки й опис із RSS, без перекладу та ідей постів.

## Налаштування (один раз, ~15 хвилин)

### 1. Telegram-бот і канал
1. У Telegram відкрийте [@BotFather](https://t.me/BotFather) → `/newbot` → придумайте ім'я. Збережіть **токен** вигляду `123456:ABC...`.
2. Створіть канал (або візьміть наявний) → *Адміністратори* → додайте бота з правом **публікувати повідомлення**.
3. **ID каналу**:
   - публічний канал: просто `@назва_каналу`;
   - приватний канал: перешліть будь-який пост із каналу боту [@userinfobot](https://t.me/userinfobot) або [@getidsbot](https://t.me/getidsbot); ID має вигляд `-100xxxxxxxxxx`.

### 2. Ключ Claude (необов'язково, але дуже бажано)
[console.anthropic.com](https://console.anthropic.com) → *API Keys* → *Create Key*. Поповніть баланс на мінімальну суму: цього вистачить надовго.

### 3. Секрети в GitHub
Репозиторій → *Settings* → *Secrets and variables* → *Actions* → *New repository secret*:

| Назва | Значення |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен від BotFather |
| `TELEGRAM_CHAT_ID` | `@назва_каналу` або `-100…` |
| `ANTHROPIC_API_KEY` | ключ Claude (можна не додавати) |

### 4. Перший запуск
Вкладка *Actions* → **Daily AI digest** → *Run workflow*:
1. `check-sources`: покаже, які RSS-стрічки працюють (✅/⚠️/❌). Непрацюючі вимкніть у `config.yaml` (`enabled: false`) або виправте адресу.
2. `dry-run`: збере дайджест і надрукує його в лог, у канал нічого не піде.
3. `send`: справжня відправка в канал. Далі бот працює сам щодня о ~9:00 за Києвом.

## Як змінювати (без програміста)

Усе налаштовується у файлі [`config.yaml`](config.yaml): його можна редагувати прямо на GitHub (іконка ✏️).

- **Додати джерело**: допишіть рядок у `sources`:
  ```yaml
  - {name: Назва сайту, url: "https://site.com/feed/", category: archviz, require: [ai]}
  ```
  RSS-адресу сайту зазвичай можна знайти, дописавши до адреси `/feed`, `/rss` або `/rss.xml`.
  `require: [ai]` означає, що стаття мусить згадувати ШІ; для сайтів, які й так повністю про ШІ в креативі, ставте `require: []`.
- **Додати пошуковий запит**: рядок у `google_news.queries`.
- **Більше чи менше статей**: `settings.top_n` і `settings.min_score`.
- **Опис аудиторії**: `llm.audience`. Від нього залежить, що ШІ вважатиме важливим.
- **Ключові слова**: `keywords` (перший фільтр, до ШІ).
- **Час публікації**: `cron` у `.github/workflows/daily-digest.yml` (час в UTC).

## Локальний запуск (для розробки)

```bash
pip install -r requirements.txt
python -m digest --check-sources        # перевірити джерела
python -m digest --dry-run              # показати дайджест у терміналі
python -m digest --dry-run --no-llm     # без ШІ
python -m pytest                        # тести
```

Змінні середовища: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `ANTHROPIC_API_KEY`.

## Структура

```
config.yaml                 налаштування, джерела, ключові слова
digest/fetch.py             завантаження RSS і Google News
digest/filters.py           свіжість, ключові слова, дублі
digest/extract.py           повний текст статті (trafilatura)
digest/llm.py               оцінка і підсумки через Claude
digest/telegram.py          форматування і відправка
digest/state.py             пам'ять про надіслані статті (data/seen.json)
.github/workflows/          щоденний запуск у GitHub Actions
```

## Відомі обмеження

- Адреси RSS у `config.yaml` поки не перевірені: після першого `check-sources` частину доведеться виправити.
- Для посилань із Google News повний текст не витягується (це редиректи), тому ШІ оцінює їх лише за заголовком.
- Сайти без RSS і соцмережі (Instagram, X, LinkedIn) поки не охоплені. Це наступний крок (Apify).
- Reddit інколи блокує запити з серверів GitHub. Якщо так, вимкніть ці джерела.
